# Anand Enterprises Website

Responsive single-page website for Anand Enterprises, a wholesale distribution and retail supply business in Samastipur, Bihar.

## Included
- Homepage and brand catalogue: Bisk Farm, Jyothy Labs, Amber, Everest, Lotte, Pramod and Rungta
- Contact numbers: 9304686535 and 9931504070
- WhatsApp enquiry links and Google Maps directions
- Responsive mobile/desktop layout

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. Wait for GitHub Pages to publish the site.

Note: This repository version uses a vector logo and a designed hero background. The original storefront photo has not yet been uploaded to this repository.
